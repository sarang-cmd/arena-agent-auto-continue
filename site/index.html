Long agent runs should not end on a formality.

Arena's agent stops when it reaches its tool-call limit for the turn. It is waiting for one word. This extension types it for you, once per banner, and then leaves the page alone.

It reads one banner, not your conversation.

The extension looks for a single sentence near the end of the page. When that sentence appears, it writes continue into the message box and sends it.

the exact line
The agent reached the tool-call limit for this turn. Send a message to continue where it left off.
where it looks
Text nodes from the bottom of the page upward, stopping at the first match. A long conversation costs a few milliseconds, not a full scan.
what it ignores
The line "send a message to continue" on its own is not enough. The words about the tool-call limit have to be present too, so ordinary chat text cannot trigger it.
how it sends
It fills the composer with a real input event and clicks the send button next to it. If there is no button, it presses Enter. Both paths are tested.
when it stops
After one send it disarms until the banner has been gone for a moment. A re-render that flickers the same banner will not produce a second message.

Defaults that assume you are not watching.

Everything below is a setting in the popup. These are the values it ships with, and why each one is there.

Open the toolbar icon on any arena.ai page to change a value or stop it entirely.

Setting Default Why it is set that way
Delay before sending 1200 ms Lets the page finish rendering the banner, so the composer is ready to take text.
Skip if the composer has text on If you already typed something, your draft wins. It never overwrites what you wrote.
Only when the tab is visible on Stops two background tabs from both answering the same agent.
Safety cap 30 sends A ceiling for unattended runs. Hitting it pauses the extension until you reset the counter.
Message continue Any short message works. Extra instructions are a bad idea, since the agent reads this mid-task.
Repeat guard 6 s The same banner cannot trigger another message inside this window. An agent cannot spend a whole tool budget in six seconds.

Install it in about a minute.

The extension is not in the Chrome Web Store. You load the packed release folder yourself, which also means you can read every line of it first.

  1. Download the latest release

    Grab baton.zip from the releases page and unzip it somewhere you will keep it.

  2. Open your extensions page

    Go to chrome://extensions. In Edge it is edge://extensions, in Brave brave://extensions.

  3. Turn on developer mode

    The switch is in the top right corner of that page. Loading an unpacked folder needs it.

  4. Load the unzipped folder

    Choose "Load unpacked" and select the folder that contains manifest.json. The chevron icon appears in your toolbar.

  5. Open the agent page

    Visit arena.ai/agent and start a task. A small pill in the bottom corner tells you it is watching, and how many times it has sent so far.

Questions worth asking before you install it.

If something here is wrong for your setup, the answer is probably that you should not run it.

Can it send a message over and over in a loop?
It sends one message per banner appearance, then waits for the banner to leave the page for at least a moment before arming again. Identical banners are ignored for six seconds after a send. On top of that, the safety cap stops it after 30 messages in a row.
Does it read or send my conversations anywhere?
No. The content script runs on arena.ai pages and nothing else. It has no network code and no analytics, and the only thing it stores locally is your popup settings and a counter. The privacy page lists exactly what is kept.
What happens if Arena changes the wording?
It stops working quietly, which is the safe failure. Nothing is sent, and the pill keeps saying it is watching. The match is a case-insensitive pattern around "reached the tool-call limit", so small wording changes usually still match.
Will it interfere with a message I am already writing?
Only if you turn off the draft guard. With it on, the extension checks the composer first and does nothing when there is text in it.
Why not just click the button for me when the agent is idle?
Because an idle agent and a thinking agent look the same from outside. Guessing produces duplicate messages in a conversation you then have to untangle. Reacting to the one banner that names the limit is narrow, and narrow is the point.
Is this affiliated with Arena?
No. It is an independent extension that reads a page in your browser. Arena has no involvement and makes no promises about it.
